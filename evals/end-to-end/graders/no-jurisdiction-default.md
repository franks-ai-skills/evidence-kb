The request names no country, audience location, or language. PASS only if the brief records location, languages, and jurisdiction explicitly, each with its basis, and treats any choice that is not stated in the request as an assumption (for example "international, no specific jurisdiction", or a basis found in the repository), instead of silently assuming one country. It must also contain an assumptions table that replaces questions to the user.
